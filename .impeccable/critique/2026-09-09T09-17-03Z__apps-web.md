Fix: confirm step (total+recipient+warnings), disable+spinner, explicit ack/block on risk, persistent sent record. -> /impeccable harden
- [P1] Decorative dead chrome erodes trust and inflates cognitive load. Wire high-value (Siparişler, Dia, Taslaklar, ⌘K) or remove/mark "coming"; promote AI Kutusu to product home. -> /impeccable distill
- [P1] No keyboard support or visible focus for the core loop. No :focus-visible anywhere; ⌘K unwired; no list arrow-nav. Fix: focus-ring token on all interactives; wire ⌘K; arrow nav + Enter. -> /impeccable adapt
- [P2] Analyze-failure state misleading and transient (phase resets to idle). Add phase="error" + inline error card + Retry. -> /impeccable harden
- [P2] "Yeniden oluştur" can't update the visible draft. DraftBlock useState(analysis.draftText) never re-keyed; regenerated text never appears, edits at risk. Fix: key on message/analysis id or sync via effect. -> /impeccable harden
